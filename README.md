# AurigmaInternship
Информационный репозиторий для практикантов Aurigma

## ReadMe.Md

ReadMe.Md - один из обязательных атрибутов репозитрия. С него пользватель продукта или разработчик кода начнет свой путь. Информативный, структурированный и красиво оформленный репозиторий привлекут внимание к проекту и облегчат работу с ним. 

В описание стоит добавить:
- Краткая аннотация проекта.
- Где можно скачать собранный проект или посмотреть его вживую.
- Краткая инструкция по использованию и/или ссылка на полную инструкцию.
- Что необходимо для сборки/запуска, какие версии NodeJS/.NET/СУБД/других SDK и инструментов.
- Как собрать проект из командной строки. Этот раздел обязателен, даже это стандартные npm install/npm run build или dotnet build.
- Как подготовить дистрибутив или опубликовать пакет, а так же где появится результат.
- Если поддерживается Docker, то как собрать образ и как его запустить.- 
- Как запускать тесты (или отметить, что их нет).
- Правила оформления пулл реквестов, включая применение средств автоформатирования и т.п.
- Лицензия.
- Как оставить обратную связь.

## Структура репозитория

Хорошая структура облегчает поиск в репозитории и показывает то, что в нём есть.
ОБщая идея заключается в разделении кода и сопутствующих данных и разделении слабо связанных блоков кода друг от друга. Несмотря на то, что с течением времени код и докуменатация будет менятся, структура должна быть создана и затем менятся для поддержки изменений.

Хорошим начальным вариантом будет создание отдельных верхнеуровневых папок:

- docs - документация и связанные документы
- src - для кода
- libs - для сторонних библиотек
- tools - утилиты, помогающие работе с проектом.

- и т.д.


Структура в папке src будет определятся языком проекта и состоит ли он из нескольких разнородных модулей.
